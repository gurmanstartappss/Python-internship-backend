event loop :- it is the central mechanism that schedules and runs asynchronous tasks, when one task is waiting for I/O, the event loop can run another ready task

A coroutine is a special function that can pause its execution and resume later.In Python, coroutines are commonly created using async def and run with await.

AsyncIo library: built in python lib--event loop, coroutine, task, await, gather(), create_task(), lock, queue

Blocking and Non-Blocking: blocking code stop the current thread from doing other work.
inside an async application, blocking code can prevent the event loop from serving other tasks.
