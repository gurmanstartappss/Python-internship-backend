Stateless vs Stateful

The easiest way to remember:

Stateless = doesn't remember previous requests
Stateful = remembers previous requests

Feature	                        Stateless	Stateful
Remembers client information?	No	        Yes
Each request independent?	    Yes	        No
Server stores session/state?	Usually no	Yes
Simpler to scale?	            Yes	        More difficult
Example	                        REST API	Online shopping session
