Threading: 

it is a lightweight execution unit within a process.multiple threads share the same process memory


start():  Begins thread execution. It allocates system resources and internally invokes the run() method in a separate call stack.
run():  Serves as the entry point for the thread's execution logic. It contains the actual code intended to run concurrently.
sleep(long millis): Pauses the currently executing thread for a specified timeframe. This transitions the thread into a TIMED_WAITING state.
join(): Blocks the calling thread until the target thread completely finishes its execution.
yield(): Provides a hint to the thread scheduler that the current thread is willing to yield its current use of a processor
