pip install Django---------------install Django
pip freeze > requirements.txt----freeze pip and create txt having requirements
pip install -r requirements.txt--after project, all requirements updated in txt file
django-admin startproject headq--created project named as headq
cd headq-------------------------going into headq folder

→ Database setup: create migration files, apply them to DB, and create admin user.
python manage.py makemigrations---create migration files for model/database changes
python manage.py migrate----------apply migrations to the database
python manage.py createsuperuser--create an admin/superuser account
